# ADR-0001: The choices live here, not in the code

- Status: Accepted · 2026-09-10 · Jérémie Lumbroso (CC BY 4.0)

**Decision**: Every non-obvious choice in this repository is recorded as an
ADR — this folder is the repo's memory, and reading it is how you inherit
UNDERSTANDING rather than just files.

**Why this matters more than the code**: The code you can regenerate in one
conversation with a model. The REASONS — why this stack, why this transport,
why free-tier hosting with its cold starts — are the part that disappears
when a person (or a context window) moves on. Writing them down is called
epistemic continuity, and it is the same practice this course teaches for
your own thinking: an artifact needs to have the thoughts somewhere.

**How to disagree**: Don't edit this file. Write `0004-your-title.md` saying
what you're changing and why. The record grows; it never silently mutates.

**If wrong**: If you find yourself never reading these, tell us — a memory
nobody consults is furniture, and that finding would itself be worth an ADR.
